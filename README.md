# Dipjoy Howlader Portfolio

A premium static portfolio website for four video-editing niches.

## Files
- `index.html` — homepage
- `category.html` — reusable category page
- `videos.json` — portfolio video catalog
- `admin.html` — Cloudinary upload helper
- `app.js` / `styles.css` — functionality and design

## Setup
1. Create a Cloudinary account.
2. Create an unsigned upload preset restricted to video files. For a public site, keep strict limits.
3. Open `admin.html` locally or on your deployed site.
4. Enter your Cloudinary Cloud Name and Upload Preset.
5. Choose a category and project title.
6. Upload your MP4/WebM/MOV.
7. Copy the JSON entry generated by the page.
8. Open `videos.json`, add the entry before the final `]` (separate entries with commas).
9. Push the changed files to GitHub.
10. Clients visit the deployed site and open a category.

## Important
The included admin page is intentionally a lightweight upload helper, not a secure multi-user CMS. Anyone who can access it can upload if they know the preset. Keep `admin.html` private or remove it from the public deployment after setup. For a real production CMS, use authentication + signed Cloudinary uploads + a database.

GitHub Pages can host the static site. Cloudinary hosts the videos.
